## HTML, CSS, JavaScript (Front-End)
| এক্সটেনশন                            | কাজ                                                                 |
| ------------------------------------ | ------------------------------------------------------------------- |
| **HTML CSS Support**                 | HTML ফাইল লেখার সময় CSS class autocomplete                          |
| **Auto Rename Tag**                  | একটি HTML ট্যাগ পরিবর্তন করলে closing tag স্বয়ংক্রিয়ভাবে পরিবর্তন |
| **Auto Close Tag**                   | `<div>` লিখলে স্বয়ংক্রিয়ভাবে `</div>` যোগ করে                     |
| **Prettier - Code Formatter**        | কোড সুন্দর ও সঠিকভাবে ফরম্যাট করে                                   |
| **IntelliSense for CSS class names** | CSS class autocomplete (HTML/JSX-এ)                                 |
| **Path Intellisense**                | ইমেজ/ফাইল পাথে autocomplete                                         |
| **Live Server**                      | কোড সেভ করলে সাথে সাথে ব্রাউজারে রিফ্রেশ                            |
