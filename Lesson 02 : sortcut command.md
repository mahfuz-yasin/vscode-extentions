# 🔹 VS Code শর্টকাট GitHub কাজের জন্য

## 🖊️ 1. মৌলিক কোড এডিটিং

| কাজ                             | শর্টকাট                              |
| ------------------------------- | ------------------------------------ |
| কোড ফরম্যাট করা                 | `Shift + Alt + F`                    |
| একই ভেরিয়েবল একসাথে বদলানো      | `Ctrl + D` (বারবার চাপলে)            |
| সব মেলানো জায়গায় এডিট           | `Ctrl + Shift + L`                   |
| লাইন ডুপ্লিকেট                  | `Shift + Alt + Down`                 |
| লাইন উপরে/নিচে সরানো            | `Alt + ↑` / `Alt + ↓`                |
| একসাথে বহু কার্সর বসানো         | `Ctrl + Alt + Down` বা `Alt + Click` |
| মন্তব্য করা (comment/uncomment) | `Ctrl + /`                           |

---

## 🔹 2. Git শর্টকাট (VS Code থেকে সরাসরি)

| কাজ                         | শর্টকাট                                      |
| --------------------------- | -------------------------------------------- |
| Source Control প্যানেল খোলা | `Ctrl + Shift + G`                           |
| Git commit করা              | `Ctrl + Enter` (Source Control ট্যাবে থাকলে) |
| Commit + Push একসাথে        | `Ctrl + Shift + P` → `Git: Push`             |
| Git pull                    | `Ctrl + Shift + P` → `Git: Pull`             |
| Git branch পরিবর্তন         | `Ctrl + Shift + P` → `Git: Checkout to…`     |
| নতুন branch তৈরি            | `Ctrl + Shift + P` → `Git: Create Branch`    |
| Git diff দেখা (পরিবর্তন)    | Source Control → ফাইল ক্লিক                  |
| Undo last commit (amend নয়) | `Ctrl + Shift + P` → `Git: Undo Last Commit` |

---

## 🔹 3. GitHub Integration শর্টকাট

> যদি **GitHub Pull Requests and Issues** এক্সটেনশন ইনস্টল থাকে

| কাজ               | শর্টকাট                                            |
| ----------------- | -------------------------------------------------- |
| Pull Request দেখা | `Ctrl + Shift + P` → `GitHub: Pull Requests`       |
| Issue লিস্ট খোলা  | `Ctrl + Shift + P` → `GitHub: Issues`              |
| PR checkout করা   | কমান্ড প্যালেট থেকে `Checkout Pull Request`        |
| PR তৈরি করা       | `Ctrl + Shift + P` → `GitHub: Create Pull Request` |

---

## 🔹 4. Navigation শর্টকাট

| কাজ                                  | শর্টকাট            |
| ------------------------------------ | ------------------ |
| ফাইল ওপেন                            | `Ctrl + P`         |
| ফাইলে লাইন নাম্বার জাম্প             | `Ctrl + G`         |
| প্রজেক্ট সার্চ                       | `Ctrl + Shift + F` |
| সিম্বল সার্চ (function/class খুঁজতে) | `Ctrl + Shift + O` |
| প্রজেক্ট সিম্বল সার্চ                | `Ctrl + T`         |

---

## 🔹 5. Terminal শর্টকাট (GitHub CLI বা Git কমান্ডের জন্য)

| কাজ                       | শর্টকাট                       |
| ------------------------- | ----------------------------- |
| টার্মিনাল খোলা/বন্ধ       | \`Ctrl + \`\` (backtick)      |
| নতুন টার্মিনাল            | \`Ctrl + Shift + \`\`         |
| টার্মিনালগুলোর মধ্যে সুইচ | `Ctrl + PgUp` / `Ctrl + PgDn` |
| Clear টার্মিনাল           | `Ctrl + K`                    |

👉 টার্মিনালে আপনি `git add .`, `git commit -m "msg"`, `git push` ইত্যাদি রান করতে পারবেন।

# ⚡ Bonus: GitHub Workflow (VS Code শর্টকাট + Git কমান্ড)

1. **ফাইল এডিট করুন**
2. `Ctrl + S` → সেভ
3. `Ctrl + Shift + G` → Source Control ওপেন
4. পরিবর্তিত ফাইল সিলেক্ট করুন
5. মেসেজ লিখে → `Ctrl + Enter` → Commit
6. `Ctrl + Shift + P` → `Git: Push`
